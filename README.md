# ASP.Net MVC - Exercice 01
Réaliser une site de voyage en ASP.Net MVC. 

## Contraintes
- Partir d'une nouvelle solution.
- Le visuel du site devra être basé sur le template "sail_trip-web" fourni.
- Utilisation de services pour les données
  - Les fichiers sont fournis :slight_smile:
  - Il n'y a pas d'acces à une base de donnée.
- Exercice solo *(pas d'utilisation d'IA générative :robot:)*
- L'utilisation de git est obligatoire
- Les fichiers static (image, css, etc...) doivent être placer dans « wwwroot »

## Page
- Accueil
- Liste des destinations
- Détails d'une destinations
- Un blog (prévoir une pagination par page)
- A propos
- Contact avec un formulaire (submit non traité)

## Information complémentaire
La demande du client peut évoluer à tout moment.
